# Weather App

A simple weather application built using HTML, CSS and JavaScript.

## Features

- Search weather by city
- Fetch weather data from a public API
- Loading state
- Error handling
- Display temperature and humidity

## Technologies

- HTML
- CSS
- JavaScript
- REST API
- Fetch API
- Async/Await

## How to Run

Open `index.html` in a web browser.
